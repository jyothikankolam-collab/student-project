# Student Management System

## Project Overview
The Student Management System is a web-based application developed using Python and Django. It helps manage student information efficiently using CRUD operations.

## Technologies Used
- Python
- Django
- SQLite
- HTML5
- CSS3
- Bootstrap (if used)

## Features
- Add Student Details
- View Student Details
- Update Student Information
- Delete Student Records
- Manage student data using SQLite

## Database
SQLite is used to store and manage student information.

## Installation and Setup

1. Clone the repository:
   `git clone YOUR_REPOSITORY_URL`

2. Navigate to the project folder:
   `cd student-project`

3. Create a virtual environment:
   `python -m venv venv`

4. Activate the virtual environment (Windows):
   `venv\Scripts\activate`

5. Install dependencies:
   `pip install -r requirements.txt`

6. Apply migrations:
   `python manage.py migrate`

7. Run the development server:
   `python manage.py runserver`

8. Open in browser:
   `http://127.0.0.1:8000/`
